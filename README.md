# AramCodeLab videos

The source code of the AramCodeLab math videos: [Manim](https://www.manim.community/) animations with an
offline AI narrator. Every video lesson follows a section of the free course on
[AramCodeLab](https://aramcodelab.pythonanywhere.com/), where the full text, proofs, problems with
solutions and runnable Python code live.

| Folder | Video | Narration |
|---|---|---|

| [`prob02-probabilities/`](prob02-probabilities/) | Probability Theory · Lesson 2: Probabilities in Discrete Sample Spaces (12:08) | Orpheus, Tara |
| [`bayes/`](bayes/) | A positive test: am I ill? | Kokoro |
| [`arcsine2/`](arcsine2/) | The Arc Sine Law | Kokoro |
| [`kit_demo/`](kit_demo/) | A short demo of the lesson kit | Kokoro |

More lessons of the Probability Theory course are added as they are released.

## How a video is made

Each video folder `X/` contains:
- `SCRIPT.md`: the narration together with the visual plan;
- `script.py`: the same narration as `SEGMENTS = [(key, text), ...]`, split at the visual cues;
- `data.py`: every number shown on screen, computed in code with fixed seeds;
- `scenes.py`: the Manim scene;
- `youtube.txt`: the video description with chapters.

The scene opens `with self.seg('key') as g:` for each narration segment, so animations are timed to the
voice (`g.left()` is the narration time still to come). The timings come from `X/audio/durations.json`,
which is committed, so you can render every video without generating the voice.

Shared code is in [`lib/`](lib/):
- `brand.py`: colours, fonts and the background of the AramCodeLab style;
- `prob_visuals.py`: probability pictures shared by the course lessons (ball arrangements, dice grids, coins);
- `lesson_kit.py`: building blocks for course lessons (title card, definition and theorem boxes,
  derivations, code cells with their output, sample-point diagrams, the Key ideas recall card, end card);
- `narrate.py`: the Kokoro voice, the `Narrated` scene base class, and the final audio mix;
- `orpheus_voice.py`, `asr_check.py`, `check_voice.py`, `tighten_pauses.py`: the Orpheus voice and its checks.

## Render a video

Install Manim's system dependencies first (ffmpeg, Cairo, Pango, LaTeX), see the
[Manim installation guide](https://docs.manim.community/en/stable/installation.html). Then:

```sh
python -m venv .venv && .venv/bin/pip install -r requirements.txt
cd prob01-sample-space
../.venv/bin/manim -ql scenes.py Video      # 480p preview; -qp renders 1440p60
```

This renders the picture only. To add the narration:

1. Generate the voice clips into `X/audio/`:
   - Orpheus (Apple Silicon, `pip install mlx-audio`): `python lib/orpheus_voice.py X`;
   - or Kokoro (download `kokoro-v1.0.onnx` and `voices-v1.0.bin` into `models/`): `python lib/narrate.py voice X`.
2. Optional checks: `python lib/asr_check.py X` compares each clip with the script using Whisper,
   and `python lib/tighten_pauses.py X` shortens pauses longer than 0.9 s.
3. Render again (the timings follow the new clips), then mix the voice onto the video:
   `python lib/narrate.py mux X X/media/videos/scenes/1440p60/Video.mp4 out.mp4`.
